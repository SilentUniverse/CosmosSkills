# 历史测量：工作流运行层消融

本文对应原始报告内固定的源码身份；当前协作机制见[增量设计](../incremental-collaboration-plan.zh.md)，当前验证见[测评](../checkpoint-workflow-review.zh.md)。

**确定性消融数据。** [原始报告](workflow-ablation.json)是数值与样本的权威来源，保留源码 SHA-256、Git 基线、平台、Python 版本和所有原始计时。复现命令：

```text
python3 scripts/benchmark-workflow.py --samples 31 --output .scratch/tmp/workflow-ablation.json
```

Windows 使用已安装的 `python` 或 `py -3` 启动同一脚本。计时环境为 macOS 26.6.2 arm64、Python 3.9.6；测试进程结束后单独运行基准。每项预热 3 次、31 对交替顺序样本，以固定种子的配对中位差 bootstrap 给出 95% 区间。耗时不包含 CLI 启动和模型请求，区间只描述本次本机样本，不能推广为跨机器保证。对照是当前代码中关闭一个机制的消融，不是整个 Git 基线版本与候选版的端到端对比。

下表是串行 `cmd_step` 的进程内完整驱动耗时，包含卡片解析。卡片相互独立，每卡 10 个测试路径；纯规划微基准每卡只有 1 个路径，单独保存在原始报告中。消融分支执行并行配对后再截取第一项；两侧选中的任务与驱动输出一致。

| ready 卡数 | 串行快路径 p50，ms | 配对后截取 p50，ms | 配对次数：快路径 / 消融 | 配对耗时增量中位数的 95% 区间，ms |
| --- | ---: | ---: | ---: | ---: |
| 4 | 0.427 | 2.146 | 0 / 6 | 1.716–1.726 |
| 64 | 4.293 | 6.037 | 0 / 6 | 1.729–1.776 |
| 256 | 16.764 | 18.573 | 0 / 6 | 1.779–1.859 |

并行容量上限是 4，所以这里的配对次数为 6，并不随总 ready 数继续增长。结论是串行无须承担这项工作；毫秒级差值不足以证明 AI 任务端到端明显加速，也不支持为此新建持久调度缓存。零配对不等于总流程零新增成本：执行身份、基线和事务保护有共享的正确性成本。完整串行任务的性能非劣仍须在后续任务试跑中验证，不能由该表代替。

下表比较 orchestrator 一次取得的 brief JSON。夹具是 synthetic legacy v1 卡，未声明现代验证合同，不覆盖 v2/v3 verifier、preflight 或真实模型语义。每张历史卡有 10 个测试路径，packet 与测试清单输入保持等价。

| worker 数 | 历史卡数 | 共享 JSON / 展开 JSON，UTF-8 字节 | 复用解析 / 重读的卡片解析次数 | 复用 / 重读 p50，ms |
| --- | ---: | ---: | ---: | ---: |
| 1 | 0 | 1,076 / 1,059 | 1 / 2 | 0.451 / 0.517 |
| 1 | 32 | 10,675 / 10,658 | 33 / 34 | 3.905 / 3.969 |
| 2 | 0 | 1,883 / 1,878 | 2 / 4 | 0.587 / 0.711 |
| 2 | 32 | 11,482 / 21,076 | 34 / 36 | 4.026 / 4.154 |
| 4 | 0 | 3,497 / 3,516 | 4 / 8 | 0.845 / 1.093 |
| 4 | 32 | 13,096 / 41,912 | 36 / 40 | 4.295 / 4.541 |

4 worker、32 历史卡时，控制器输入投影减少 68.8%；单 worker 增加 17 字节，2 worker 无历史时增加 5 字节。保持一个并行 schema 比增加自适应变体更简单，串行正常路径使用 packet，不消费这份并行包装。独立 worker 仍需得到下一步必需的共享原文：JSON 指针不会自动提供跨 agent 内存。这些数值不是所有 agent 合计的 API 输入，更不是 token 或缓存命中率。

| 被消融的机制 | 保留机制的观察 | 移除机制的观察 | 决策 |
| --- | --- | --- | --- |
| 共享快照锁 | 写锁持有时拒绝并发读取 | 读取能穿过写入区间 | 保留，不能用省一次锁换一致性 |
| 首次读取版本校验 | 并发追加的备注被保留，过期写入拒绝 | 并发备注丢失 | 保留 |
| 批次基线差分 | 文件系统的历史不变、添加、修改、删除 4 个反例全部符合预期 | 全量现存清单仅 2/4 符合预期：误拦历史，漏掉删除 | 保留差分；另外验证批次身份和 Git 路径边界 |
| 脚本预检 | [mock runner 回归](../../tests/test_overnight.py)只有实施与收尾 2 次模型启动边界 | 增加一轮准备时，反事实推算为 3 次；原始报告没有执行该项消融 | 机械准备交给脚本；实际模型时延未测 |


模型质量、provider token、缓存命中和人机端到端收益不属于这份确定性消融数据。
