# Tooling

Focused setup, migration, and project or host tooling skills. The main workflow lives in [workflow](../workflow/README.md).

- **[verify](./verify/SKILL.md)** — Build and maintain project-local tools to operate real application behavior, observe results, and replay verification scenarios.
- **[shell-guardrails](./shell-guardrails/SKILL.md)** — Select and install a combined or narrow hook for destructive Git, push blocking, MSYS path safety, and modern CLI enforcement.
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** — Migrate test files from `as` type assertions to @total-typescript/shoehorn.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** — Set up Husky pre-commit hooks with lint-staged, Prettier, type checking, and tests.
