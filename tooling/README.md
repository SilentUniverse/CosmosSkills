# Tooling

Focused setup, migration, and project or host tooling skills. The main workflow lives in [workflow](../workflow/README.md).

- **[verify](./verify/SKILL.md)** — Build and maintain project-local operation, observation and formal-checking capabilities, with replayable evidence and source correspondence; UI, device and desktop drivers follow one control adapter contract.
- **[shell-guardrails](./shell-guardrails/SKILL.md)** — Select and install a combined or narrow hook for destructive Git, push blocking, MSYS path safety, and modern CLI enforcement.
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** — Migrate test files from `as` type assertions to @total-typescript/shoehorn.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** — Set up pre-commit hooks by extending the existing hook manager or the ecosystem-native tool (Husky + lint-staged for JS/TS projects without one), with formatting, type checking, and tests.
